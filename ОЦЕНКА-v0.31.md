## Что сделано

### Права: «сотрудник видит только свои»
- У участника пространства есть переключатель **«видит всё / только свои»** (Настройки → Команда, меняет владелец). «Только свои» — сотрудник видит и правит записи, задачи, историю и диалоги, где он ответственный, плюс записи без ответственного и ничьи входящие.
- Проверяет **база** (`can_see`, `can_see_record` в RLS на `records`, `tasks`, `activities`, `chats`): чужие строки такому сотруднику не отдаются даже прямым запросом к API с его ключом — экран тут ни при чём.
- Распределение заявок остаётся в «Куда падают заявки» («по очереди» или на конкретного человека), так что у сотрудника с «только свои» новые заявки всё равно появляются.

### Ответы в Instagram через Meta
- В карточке Instagram — поле для **токена страницы Meta**; токен уходит в базу пространства (`channel_hooks.bot_token`, читает только владелец и функция), в браузере не остаётся.
- Ответ из «Входящих» идёт `POST hook?action=send` с JWT пользователя → функция проверяет, что он участник пространства, и шлёт через Graph API `me/messages`. Не доставлено — пузырь помечается неотправленным, как у остальных каналов. Без токена — прежнее честное «пока только приём».

### ВКонтакте (сообщения сообщества)
- Приёмник **Callback API**: адрес — наш `hook?src=vk`, строка подтверждения из настроек сообщества хранится в `channel_hooks.meta`, функция отвечает ею на проверочный запрос и «ok» на события (иначе VK шлёт повторы). Имя собеседника — `users.get` по токену сообщества; ответы — `messages.send` через сервер.
- Карточка с тремя шагами и кнопкой в кабинет сообществ; маршрут «ВКонтакте» в «Куда падают заявки»; метка VK в диалогах.

### Авито (сообщения по объявлениям)
- Владелец вводит `client_id`/`client_secret` приложения → функция (`action=setup`) сама получает токен `client_credentials`, узнаёт id аккаунта (`core/v1/accounts/self`) и регистрирует вебхук `messenger/v3/webhook` на приёмник. Секрет приложения в браузере не хранится, токен обновляется по сроку.
- Свои же исходящие (author_id = наш аккаунт) в заявки не превращаются; ответы — `messenger/v1/.../messages` через сервер.

### Утренний дайджест задач в Telegram
- `pg_cron` в 05:00 UTC (08:00 МСК) дёргает `hook?digest=<ключ из app_settings>`; функция для каждого пространства с подписчиками собирает задачи на сегодня и просроченные **по сотрудникам**, число новых заявок за сутки — и шлёт тем же получателям, что и уведомления о заявках.
- Тумблер «Утренний дайджест задач» в карточке уведомлений (владелец). Выключение — строка `channel_hooks(source='digest', secret='off')`.

### Excel (.xlsx) на входе
- Читается **без библиотек** (`src/lib/xlsx.ts`, ~170 строк): zip распаковывает встроенный `DecompressionStream`, XML разбирает `DOMParser`. Первый лист, общие и встроенные строки, даты и дата-время по стилям ячеек (→ `12.03.2025 14:22`, как ждёт импорт), телефоны-числа без `E+10`, числа без плавающего мусора (`0,30000000000000004` → `0.3`), логические «да/нет», пустые строки выброшены, второй лист не трогается. SheetJS положил бы в single-file ещё ~400 КБ.
- Старый бинарный `.xls` (Excel 97–2003) честно отклоняется с подсказкой пересохранить в `.xlsx`.
- Проверено на файлах от openpyxl и от LibreOffice (разные писатели XML).

### Копия облака
- В облачном режиме карточка «Копия облака»: JSON в том же формате, что и локальная база (записи, задачи, история, переписка без личного Telegram, настройки конструктора). Файл открывается на любом устройстве через «Загрузить копию» в режиме «только это устройство» — данные всегда можно забрать с собой. Это и есть страховка вместо `pg_dump` по расписанию: без токенов в CI и без чужих машин.

### Сервер (hook 0.24)
- Источник вебхука проверяется по списку: служебные строки `channel_hooks` (`notify`, `digest`) нельзя использовать как ключ приёмника (`src=digest&k=off` → 400).
- Отправка (`action=send`) и настройка Авито (`action=setup`) — только по JWT участника пространства; 403 иначе.

## Что не сделано и почему
- **Свой домен для Pages** — нужен домен Глеба; после покупки: CNAME в DNS + поле Custom domain в настройках репозитория.
- **GramJS в отдельный файл** — single-file сборка оставлена сознательно (одна страница = проще хостить и переносить); при 2,6 МБ это терпимо.
- Заглушки AI-ассистента и СДЭК остаются заглушками.

## Что сделать руками владельцу
1. ВКонтакте: кабинет сообщества → ключ доступа с правом «Сообщения сообщества» + строка подтверждения → карточка ВКонтакте → адрес в Callback API → «Подтвердить», включить событие «Входящее сообщение».
2. Авито: developers.avito.ru → приложение → `client_id`/`client_secret` → карточка Авито → «Подключить».
3. Instagram: токен страницы Meta в карточке Instagram — чтобы отвечать из CRM.
4. Права сотрудников: Настройки → Команда → «только свои» тем, кому не нужна вся база.
5. Дайджест включён по умолчанию у всех, кто подписан на уведомления, — выключается тумблером.
