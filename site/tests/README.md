# Проверки XXLcrm

Двадцать семь наборов Playwright-сценариев, которые прогоняются по собранному приложению
(`python3 -m http.server 8099` в `dist/`, `NODE_PATH=$(npm root -g) node tests/NN-*.mjs`; тест 02 ждёт `clients.csv` в текущей папке).
Вместе — 535 проверок: от «создаётся ли запись» до переезда из amoCRM/Битрикс24, автоматизаций с сообщениями по шаблону и устойчивости во второй вкладке.

| Файл | Что проверяет | Проверок |
|---|---|---|
| `01-marshruty-poisk-kalendar.mjs` | маршруты приёма заявок, палитра Ctrl+K, живой календарь, память вкладок, целостность конструктора | 22 |
| `02-import-onbording.mjs` | загрузка CSV из Excel (cp1251, «;»), дедуп, чеклист настройки, живые кнопки | 14 |
| `03-filtry-massovye-vygruzka.mjs` | фильтры по полям и свои сегменты, массовые действия, выгрузка CSV, вкладка «Сводка», поле на лету | 9 |
| `24-kanaly-i-stadii-ponyatny.mjs` | каналы: ссылки «куда идти», список подключения, стадия приёма в конструкторе, ползунок | 38 |
| `25-pereezd-iz-amo-i-bitrix.mjs` | переезд из amoCRM/Битрикс24: стадии, даты, ответственные, ФИО, телефон, связи, ID | 45 |
| `26-avtomatizacii-soobshchenie-i-tishina.mjs` | автоматизации: «ждёт ответа», «за N дней до даты», сообщение по шаблону | 51 |

| `04-polnyy-progon.mjs` | весь проект: записи и поля, стадии, автоматизации (правило реально ставит задачу), задачи, Входящие, конструктор, отмена, настройки, устойчивость, пресеты | 33 |

## Как запускать

```bash
cd site && npx vite build                 # собрать
cd dist && python3 -m http.server 8099 &  # раздать на 127.0.0.1:8099
node site/tests/04-polnyy-progon.mjs      # прогнать набор
```

Требуется `npm i -g playwright`. Браузер берётся по прямому пути — правьте `executablePath`
под свою машину (в песочнице это `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`).

Набор `02` читает `clients.csv` из этой папки — поправьте путь в файле, если запускаете не из песочницы.

## Что важно знать, когда пишете новые проверки

- Класс `.eyebrow` делает текст ЗАГЛАВНЫМ: `innerText` вернёт «ДИАЛОГИ», поэтому регулярки — с флагом `/i`.
- Первая кнопка в строке таблицы — чекбокс выделения; карточка открывается кликом по названию во второй ячейке.
- Клик по ячейке таблицы открывает inline-редактор и «съедает» Ctrl+Z — перед проверкой отмены уводите фокус.
- Без интернета в консоли будут ошибки Supabase и шрифтов — это норма, фильтруйте их.
